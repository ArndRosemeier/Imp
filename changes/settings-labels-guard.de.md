# Die Optionen bleiben lesbar

- Eine Prüfung stellt jetzt sicher, dass jede Einstellung, die Imp speichert, entweder einen Namen in Worten in den Optionen hat oder als etwas verborgen bleibt, das die App für sich selbst aufbewahrt. So können interne Werte wie die Liste geschlossener Tipps dort nicht wieder auftauchen.
