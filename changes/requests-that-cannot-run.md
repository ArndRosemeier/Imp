# No more approvals for requests that would only fail

- When an agent asks for something that cannot run, such as a picture while no picture model is chosen, it is no longer put in front of you for approval. The agent is told right away what is missing, for example which model to choose in Settings, and the budget without approval works again once it is set.
- Requests with details that don't fit are turned down at once too, so the agent can fix them instead of waiting for you.
