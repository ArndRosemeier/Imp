# Einstellungen mit eigener Länge und ein erster Schnitt, der sie kürzt

- Jede Einstellung sagt jetzt, wie lange sie im Schnitt dauert und warum: ein Blick ein, zwei Sekunden, eine Zeile so lange, wie sie zu sprechen dauert, ein Gang so lange wie der Gang. Der Clip Designer plant unterschiedliche Längen, statt jede Einstellung gleich lang zu machen.
- Clips werden etwas länger erstellt, als die Einstellung dauert, damit der Schnitt später einsteigen und früher aussteigen kann, im besten Moment.
- Eine Zeile, die im Bild gesprochen wird, zählt jetzt zur Länge ihres Clips, damit Zeilen nicht mehr gequetscht werden.
- Neu im Schnitt: **Auf geplante Länge kürzen** kürzt alle Einstellungen in einem Schritt auf ihre geplante Länge, oder nur die gewählte. Der Film Editor macht so einen ersten Schnitt, legt dann jeden Schnitt auf eine Bewegung, einen Blick oder das Ende einer Zeile und fragt vorher, wenn er nicht sicher ist, ob du einen willst.
