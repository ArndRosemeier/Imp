# Imp hält sich selbst aktuell

- Ein Imp auf dem Home-Bildschirm eines iPads (oder jede installierte Kopie) öffnet jetzt jedes Mal die neueste Version statt einer alten gespeicherten Kopie.
- Erscheint eine neuere Version, während Imp offen ist, sagt das eine kleine Leiste unten, mit der Schaltfläche **Jetzt aktualisieren**. Deine Projekte bleiben, wie sie sind.
