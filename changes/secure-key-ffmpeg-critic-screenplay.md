# A safer key, ffmpeg on request, and screenplay extras

- In the browser, your OpenRouter key is now kept encrypted. A key saved by an earlier version is encrypted the first time you open Imp, and the plain copy is removed.
- Imp on your computer now keeps the key itself, in a file only your user account can read. The browser never holds it, and every browser window starts with it.
- Imp on your computer no longer needs ffmpeg installed. It offers to download it on the Edit screen's export bar and under Settings, checks the download, and uses it at once without a restart. Until then films are recorded in the browser.
- The guide and the download explain the one-time "Open Anyway" step if your Mac or Windows warns about the unsigned download.
- The Critic is no longer among the usual roles. Add it on the Crew page under More roles when you want one.
- Script PDFs number the scenes in both margins, and dual dialogue (a name marked with ^) sits side by side, on the PDF and on the script page.
