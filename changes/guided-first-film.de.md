# Dein erster Film, Schritt für Schritt

- Eine schmale Leiste über jeder Phase zeigt die sechs Schritte zum ersten Film: die Idee, eine Szene, eine Figur, die Einstellungen, ein Clip und der Schnitt. Sie zeigt, was erledigt ist und was als Nächstes kommt.
- Die Schritte haken sich selbst ab, je nachdem, was das Projekt enthält, ob du sie von Hand erledigt hast, über einen Agenten oder sie aus dem Beispiel stammen.
- „Gehe zu“ bringt dich zur richtigen Phase. „Den Koordinator fragen“ schreibt die Bitte in das Nachrichtenfeld des Koordinators; nichts wird gesendet, bis du auf Senden drückst.
- Schließ sie dauerhaft mit dem × oder schalte alle Tipps aus. Agenten lesen dieselben Schritte mit `project.path`.
