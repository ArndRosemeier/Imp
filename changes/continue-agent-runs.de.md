# Einen unterbrochenen Agenten fortsetzen

- Läuft Imp im Browser, erinnert die Crew-Leiste dich jetzt daran, den Tab offen zu lassen, solange ein Agent arbeitet, und der Browser fragt nach, bevor du ihn mitten im Durchlauf schließt oder neu lädst. Wurde ein Durchlauf trotzdem abgebrochen oder hielt er an seiner Schrittgrenze an, macht eine Schaltfläche Fortsetzen dort weiter, wo er aufhörte.
