# Alpha-Prüfung: kleine Korrekturen in der ganzen App

- Szenenreiter lesen sich gut, wenn eine Überschrift zwei Orte enthält: „Laternenraum, Nacht / Klippenstraße, Morgengrauen“.
- Auf dem Tablet zeigt die obere Leiste wieder ihre Symbole (Bibliothek, Crew, Hilfe, Neuigkeiten); unterhalb eines breiten Desktops zeigt sie nur Symbole, damit sich nichts überlappt.
- Die Leiste „Dein erster Film“ behält ihre Schließen-Schaltfläche in der Ecke, statt auf eine leere zweite Zeile umzubrechen.
- Das Hinzufügen-Feld im Schnitt passt auf dem Tablet unter die obere Leiste.
- Die Reiter Crews und Mixe verschwinden in einer schmalen Bibliothek nicht mehr hinter dem Rand; die Reiter brechen stattdessen um.
- Ein importierter Clip sagt „Aus einer Datei · 4 s“ statt einer rohen Zahl und „nur aus Worten erstellt“.
- Die Optionen listen die internen Tipp-Schalter nicht mehr als rohe Zeilen; sie stehen unter Hilfe.
- Die Anleitung (und damit Frag Imp) erklärt, wo die Länge eines Übergangs eingestellt wird und dass der lokale Server mit ffmpeg exportiert.
