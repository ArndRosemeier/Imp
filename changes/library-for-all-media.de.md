# Eine Bibliothek für alles

- Eine Schaltfläche Bibliothek in der oberen Leiste öffnet die Bibliothek des Projekts neben jeder Phase: jedes Porträt, jeder Keyframe, jedes Orts- und Objektbild, jeder Clip, jede Dialogzeile, jeder Soundeffekt, jedes Musikstück, jede Stimmprobe, jedes Audiodokument, jede Szene und Notiz an einem Ort.
- Durchsuch sie nach Namen, Wörtern, Tags oder Notizen und filtere nach Bildern, Tönen, Clips oder Texten und nach Art. Markier Wichtiges mit einem Stern und gib allem Tags und Notizen.
- Importiere eigene Bilder, Töne, Videos und Texte (auch Untertitel) mit Importieren oder indem du Dateien auf die Bibliothek ziehst.
- Zieh einen Ton aus der Bibliothek auf eine Spur im Audio-Editor (auf dem Tablet vorher kurz gedrückt halten), oder tippe ihn an und wähle „Verwenden in …“. „Im Audio-Editor öffnen“ beginnt damit ein neues Dokument.
- Zieh einen Text aus der Bibliothek in ein beliebiges Textfeld und kopiere Elemente in ein anderes Projekt.
- Agenten nutzen dieselbe Bibliothek: Sie können alles darin auflisten, durchsuchen, lesen, mit Tags versehen, mit Notizen versehen und kopieren.
- Zieh einen Ton aus der Bibliothek auf die Audiospur im Schnitt oder auf den Ton einer Szene im Audio-Editor; eine importierte Datei wird dabei zuerst zu einem Ton dieser Szene.
- Zieh ein Bild auf eine Figur, um es zu ihrem Porträt zu machen, auf den Keyframe einer Einstellung oder auf eine Ansicht eines Orts oder Objekts. Zieh ein Video auf eine Einstellung ohne Clip, um es zu ihrem Clip zu machen, und den Clip einer Einstellung auf die Bildspur im Schnitt.
