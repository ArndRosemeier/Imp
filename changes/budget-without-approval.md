# Agents work through a whole film from one prompt

- Set a budget without approval in the Spending panel (the coins in the top bar). Agents spend
  without asking until a project's budget is used up, and the panel shows how much is left. It
  starts at $1 per project; set it to 0 to approve every paid step yourself, or add a most per step.
- Crew members are now always told which project they work in. Before, a task handed on by the
  coordinator could leave them guessing, so updates such as the development notes or shots were
  reported but not saved.
- The look and mood you ask for are kept in the film's tone, which every picture is drawn in, so
  portraits and places no longer drift to a style you did not ask for.
- When the coordinator creates and opens a new project during a run, its chat and anything waiting
  for approval move along with it instead of vanishing.
- A problem report an agent prepares now opens from a button in its chat, so its long link is never
  cut short.
