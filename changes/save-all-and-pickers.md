# Save all, Load all, and choosing where files go

- **Save all** puts everything in Imp into one .zip file: every project with its media and films, the library, saved crews, model mixes, roles, conversations, settings and help choices. Your OpenRouter key is never in it.
- **Load all** brings such a file back and replaces what is in Imp. It checks the whole file first, so a damaged file changes nothing, and it offers to save your current work before it starts.
- Find both on the Projects screen and in Settings. The coordinator can save and load everything too, and Imp then offers you the file to keep.
- Every file Imp saves (projects, films, screenplays, subtitles, sounds, backups) now opens your computer's save dialog in Chrome and Edge, so you choose the folder and the name. Safari, Firefox and tablets keep saving to downloads.
- Large workspaces of many gigabytes save and load piece by piece instead of all at once.
