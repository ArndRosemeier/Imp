# Every project has its own chats

- Each project now keeps its own chat with the coordinator and every crew member. Opening another project shows that project's chats, and agents only remember what was said in the project you are working on.
- The crew stays the same across projects, and the coordinator can still look after things that span projects: the library, saved crews, model mixes and your other projects.
- On the start screen, with no project open, agents talk in a chat of their own.
- Your earlier chats moved into the project you had open.
- **Clear chat** at the top of a chat forgets it for the current project, after asking. Other projects keep theirs. Agents can ask to clear a chat too, and you approve it.
- Duplicating, exporting and importing a project brings its chats along, and so do Save all and Load all. An imported project's chats go to the agents in the same roles.
- An agent works in one project at a time: while it works in one, it tells you so if you ask it for something in another.
