# One library for everything

- A Library button in the top bar opens the project's library beside any stage: every portrait, key frame, location and object picture, clip, line of dialogue, sound effect, piece of music, voice sample, audio document, scene and note in one place.
- Search it by name, words, tags or notes, and filter by pictures, sounds, clips or texts and by kind. Star what matters and give anything tags and notes.
- Import your own pictures, sounds, videos and texts (including subtitles) with Import or by dropping files onto the library.
- Drag a sound from the library onto a track in the audio editor (on a tablet, hold it a moment first), or tap it and choose "Use in…". "Open in audio editor" starts a new document with it.
- Drag a text from the library into any text field, and copy assets into another project.
- Agents use the same library: they can list, search, read, tag, write notes into and copy everything in it.
