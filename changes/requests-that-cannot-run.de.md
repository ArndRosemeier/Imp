# Keine Freigaben mehr für Anfragen, die nur scheitern würden

- Bittet ein Agent um etwas, das nicht laufen kann, etwa ein Bild, solange kein Bildmodell gewählt ist, wird dir das nicht mehr zur Freigabe vorgelegt. Der Agent erfährt sofort, was fehlt, zum Beispiel welches Modell in den Einstellungen zu wählen ist, und das Budget ohne Freigabe greift wieder, sobald es gewählt ist.
- Anfragen mit Angaben, die nicht passen, werden ebenfalls sofort abgewiesen, damit der Agent sie korrigieren kann, statt auf dich zu warten.
