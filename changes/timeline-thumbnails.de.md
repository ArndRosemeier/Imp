# Deine Einstellungen auf der Zeitleiste sehen

- Jedes Stück auf der Bildspur im Schnitt beginnt jetzt mit einem Standbild aus seinem Clip, aufgenommen dort, wo das Stück beginnt (oder endet, wenn es rückwärts läuft), sodass sich ein Schnitt auf einen Blick lesen lässt statt über seine Beschreibungen.
