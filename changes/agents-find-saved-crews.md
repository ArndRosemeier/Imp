# Agents find saved crews and model mixes

- Ask the coordinator to "save this crew in the library" and it saves a real crew you can load again in any project, custom roles included, instead of writing a note.
- The same goes for model mixes: "keep these models as a mix" saves one in the library's Mixes tab.
- Agents now look up every command by the words you use and by where things are in the app, such as "library crews", so they no longer think something is missing when it is only named differently.
- The guide explains the library's Crews and Mixes tabs.
