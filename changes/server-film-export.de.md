# Filme exportieren mit Imp auf deinem Computer

- Imp auf deinem Computer rendert Filme jetzt im Hintergrund, schneller als in Echtzeit, wie der Browser: Schnitte, Überblendungen, Wischblenden, Abblenden, Zooms, Farbe und alle Texte kommen gleich heraus. Auch Agenten können dort exportieren.
- Dafür wird ffmpeg genutzt; installiere also ffmpeg, um zu exportieren (Imp sagt dir, wenn es fehlt).
