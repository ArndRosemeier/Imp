# Ein sichererer Schlüssel, ffmpeg auf Wunsch und Drehbuch-Extras

- Im Browser wird dein OpenRouter-Schlüssel jetzt verschlüsselt aufbewahrt. Ein von einer früheren Version gespeicherter Schlüssel wird beim ersten Öffnen von Imp verschlüsselt, und die unverschlüsselte Kopie wird entfernt.
- Imp auf deinem Computer verwahrt den Schlüssel jetzt selbst, in einer Datei, die nur dein Benutzerkonto lesen kann. Der Browser bekommt ihn nie, und jedes Browserfenster beginnt damit.
- Imp auf deinem Computer braucht kein installiertes ffmpeg mehr. Es bietet an, ffmpeg in der Exportleiste im Schnitt und unter Optionen herunterzuladen, prüft den Download und nutzt ihn sofort ohne Neustart. Bis dahin werden Filme im Browser aufgenommen.
- Die Anleitung und der Download erklären den einmaligen Schritt „Dennoch öffnen“, falls dein Mac oder Windows vor dem nicht signierten Download warnt.
- Der Kritiker gehört nicht mehr zu den üblichen Rollen. Füg ihn auf der Seite Crew unter Weitere Rollen hinzu, wenn du einen willst.
- Drehbuch-PDFs nummerieren die Szenen an beiden Rändern, und Doppeldialog (ein mit ^ markierter Name) steht nebeneinander, im PDF und auf der Drehbuchseite.
