# Everything agents can change, you can change too

- Shots: **Clip options** under Generate set the length, size and aspect ratio of a clip, make it silent, leave out the portraits or skip starting on the key frame.
- Crew: **Change** on a member's card renames it and sets its model and how much it may spend per run.
- Crew: a new list shows what the roles need in this project, and lets you say the project goes without something, such as a cast for a film with no characters.
- Edit: **Export options** set the film's size (up to 4K), frame rate and file name, and can leave the subtitles out of the picture. Subtitles also save as .vtt.
- Edit: a sound's fade shape (linear or smooth) can be set in its inspector.
- Script: downloads can carry an author on the title page and leave out scene numbers.
- Audio: add markers (button or M) and remove them, insert silence, and duplicate a region.
- Settings: switch off agents' drafts on the Edit stage, edit number and text settings, and agents can now change the theme too.
- Projects: each project card has a delete button of its own.
