# Colour: grade shots and give the film a look

- Every shot in the Edit screen now has a Colour section: exposure, contrast, temperature, tint and saturation. "As filmed" puts it back.
- "Match colour to" grades a shot so it looks like another one in the scene: same brightness, contrast and warmth. It is a starting point you can fine-tune.
- The Look button on the film strip gives the whole film one feel: pick a preset (warm, cool, bleach bypass, noir, golden hour, night) or set it by hand.
- The preview, the exported film and the browser recording all show the same colours.
- Agents can grade shots, match them, and set the film's look with the same commands. A colour match by an agent arrives as a proposal you keep or discard.
