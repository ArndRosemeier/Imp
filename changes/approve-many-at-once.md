# Approve many requests at once

- When the crew asks for several things together, one dialog shows them all: what each request does, who asked, and what it costs, with a total for what you approve.
- Approve all, decline all, or untick the ones you don't want and decide the rest in one press. Each agent goes on as soon as everything it asked for is decided.
- Tick "Always allow" on a request to let agents do that kind of thing without asking from now on. Settings lists what is always allowed, with Ask again to take it back.
- The crew panel offers "Review all" as soon as more than one request is waiting, including requests from crew members you are not talking to.
