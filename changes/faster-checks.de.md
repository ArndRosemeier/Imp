# Schnellere Prüfungen hinter jeder Änderung

- Änderungen an Imp erreichen dich schneller: Die automatischen Prüfungen, die jede Änderung vor der Veröffentlichung besteht, laufen jetzt nebeneinander und dauern etwa halb so lang.
- Imp wird jetzt außerdem jede Nacht in einem echten Browser geprüft, auf einem Desktop-Bildschirm und einem Tablet im Querformat, einschließlich des Renderns eines Films.
