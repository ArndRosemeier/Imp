# Korrekturen aus dem vollständigen Oberflächentest

- Der Koordinator kann jetzt Dinge löschen, wenn du ihn darum bittest (eine Einstellung, eine Szene, einen Ton), immer nach deiner Freigabe. Vorher konnte er es nicht und behauptete fälschlich, es gebe keinen Löschbefehl.
- Die hervorgehobene Phase im linken Menü bleibt lesbar, wenn der Zeiger darauf ruht.
- Bei Imp auf deinem Computer gibt der Exporthinweis nicht mehr deinem Browser die Schuld, wenn ein Film in Echtzeit aufgenommen wird.
