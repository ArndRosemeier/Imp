# A quicker first run

- After the OpenRouter key, the first run now offers three model mixes: Starter (cheap, for learning and drafts), Balanced and Best. Each card shows its coordinator, its video model and what a 4 second clip costs. One tap sets every model at once.
- All three are kept as model mixes, so moving from drafts to the final film later is one switch on any stage.
- The mixes are filled from the live OpenRouter catalog, so they follow new model versions by themselves.
- Say how much help you want right there: "Guide me" shows a tip the first time each stage opens, "I know my way around" turns tips off for good. Help stays in the top bar either way.
- "Choose models myself" still lets you pick the coordinator by hand.
