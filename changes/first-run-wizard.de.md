# Ein schnellerer erster Start

- Nach dem OpenRouter-Schlüssel bietet der erste Start jetzt drei Modellmixe an: Einstieg (günstig, zum Lernen und für Entwürfe), Ausgewogen und Beste. Jede Karte zeigt ihren Koordinator, ihr Videomodell und was ein Clip von 4 Sekunden kostet. Ein Tipp legt alle Modelle auf einmal fest.
- Alle drei bleiben als Modellmixe erhalten, sodass der Wechsel von Entwürfen zum fertigen Film später ein Schalter in jeder Phase ist.
- Die Mixe werden aus dem aktuellen OpenRouter-Katalog gefüllt und folgen so von selbst neuen Modellversionen.
- Sag gleich dort, wie viel Hilfe du willst: „Führ mich“ zeigt einen Tipp, wenn eine Phase zum ersten Mal geöffnet wird, „Ich kenne mich aus“ schaltet Tipps dauerhaft aus. Die Hilfe bleibt so oder so in der oberen Leiste.
- „Modelle selbst wählen“ lässt dich den Koordinator weiterhin von Hand wählen.
