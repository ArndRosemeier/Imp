# Change models in Settings

- Settings now has a Models section where every model can be changed directly: agents, video, voice, image, sound effects, music and transcripts. Before, it only showed them.
- Switch the whole model mix there with one tap, update the mix in use, or save the models as a new mix.
- The model picker is searchable, here and on every stage, so any model in the catalog can be found, not only the first 25. It shows prices for agent models, and for video models their clip lengths and whether they make their own sound.
- Changing the agents' model changes the coordinator's model too.
- Simple on/off preferences can now be switched in Settings as well.
